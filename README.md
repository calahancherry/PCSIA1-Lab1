
        # CSS Equipment Borrowing and Reservation Management System

    ## Holy Trinity College of General Santos City

    The **CSS Equipment Borrowing and Reservation Management System** is an initial web-based interface prototype designed for the Computer Systems Servicing (CSS) Laboratory of Holy Trinity College of General Santos City.

    The proposed system aims to help students and laboratory staff manage the borrowing, returning, and reservation of CSS laboratory equipment in a more organized and efficient manner.

    ---

    ## Project Objectives

    The system prototype aims to:

    - Organize CSS laboratory equipment information.
    - Make equipment reservation easier.
    - Record borrowing and returning transactions.
    - Help laboratory staff monitor equipment availability.
    - Provide a simple and user-friendly interface.

    ---

    ## Technologies Used

    - HTML5
    - CSS3
    - JavaScript

    ---

    ## Main Features

    ### Equipment Management

    Allows users and laboratory staff to monitor available CSS laboratory equipment.

    ### Equipment Reservation

    Provides a concept for reserving equipment before laboratory activities.

    ### Borrowing Transactions

    Supports the recording and monitoring of equipment borrowing and returning.

    ### Responsive Interface

    The website is designed to work on desktop, tablet, and mobile screen sizes.

    ### User-Friendly Design

    The interface provides a simple layout that allows users to easily understand the purpose of the system.

    ---

    ## Project Category

    **Transaction Processing System (TPS)**

    The proposed system falls under the Transaction Processing System category because it is intended to record and process routine transactions such as equipment borrowing, returning, and reservations.
